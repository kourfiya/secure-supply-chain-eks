# Security Policy

## Portée

Ce dépôt est un projet de démonstration (chaîne de build sécurisée sur EKS : Trivy, cosign, Kyverno). Il n'est pas destiné à un usage en production.

## Signaler une vulnérabilité

Merci de ne pas ouvrir d'issue publique pour une faille de sécurité.

Utilisez le signalement privé GitHub : onglet **Security** > **Report a vulnerability**.

## Délais de réponse

- Accusé de réception sous 7 jours
- Premier retour d'analyse sous 14 jours

## Versions supportées

Seule la branche `main` est maintenue.
